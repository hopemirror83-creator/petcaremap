# 데이터 확보 가능성

## 공공데이터

- 2026년 4월 16일부터 기존 LOCALDATA 지방행정인허가데이터개방시스템은 폐쇄되었고, 인허가 및 생활편의 데이터는 공공데이터포털에서 이용하도록 안내되어 있습니다.
- 우선 수집 대상은 지방행정 인허가 계열의 동물병원입니다.
- 확보 기대 필드: 업체명, 업종/분류, 주소, 전화번호, 좌표, 영업상태, 인허가번호, 인허가일, 폐업일, 데이터 기준일.

## 네이버 보강

- 네이버 검색 API: 지역+동물병원/진료유형 쿼리, 블로그/카페 후기 후보, 실제 검색 노출명 후보를 수집합니다.
- 네이버 지도/지역 검색: 지도 장소명, 전화번호, 좌표, 카테고리, 지도 바로가기 URL을 보강합니다.
- 후기 원문은 복사하지 않고 제목/링크/문맥 신호만 저장한 뒤 요약합니다.

## Gemini 요약

- 직접 방문/이용한 표현은 금지합니다.
- 동물병원은 치료 효과를 단정하지 않습니다.
- 후기 부족 업체는 “현재 확인 가능한 후기는 많지 않습니다”로 처리합니다.
